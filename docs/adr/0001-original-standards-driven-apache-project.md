# Build an original standards-driven Apache-2.0 project

MoonIPFIX will be an original MoonBit implementation under Apache-2.0, designed from RFC 7011, RFC 7012, verified errata, and IANA registry metadata rather than porting an existing IPFIX library. This preserves a MoonBit-native Interface and makes copied code, generated data, fixtures, and future dependencies individually auditable.
